SUBIECT 1_id - SANTIERE / CAPITOLE (DEVIZE)

Fie un fisier JSON care contine santierele, structurat astfel:

[
  { "Cod Santier": 1, "Localitate": "Corbeanca", "Strada": "Planorului",    "Obiectiv": "Casa parter/etaj",     "Valoare": 150000 },
  { "Cod Santier": 2, "Localitate": "Corbeanca", "Strada": "Soarelui",      "Obiectiv": "Complex locuinte p+5", "Valoare": 1000000 },
  { "Cod Santier": 3, "Localitate": "Ostratu",   "Strada": "Hipodromului",  "Obiectiv": "Casa parter",          "Valoare": 200000 },
  ...
]

Fie un fisier text cu cheltuielile (cate o linie). Campul cod_capitol nu este
cheie unica, pot exista mai multe cheltuieli la acelasi capitol.

Exemplu (cod_capitol, cod_santier, denumire, um, cantitate, pret_unitar):
1,1,Fier beton,kg,13000.0,0.8
2,1,Manopera fier beton,h,300.0,30.0
1,2,Caramida,palet,26.0,500.0
...

Sa se scrie o aplicatie Java care sa indeplineasca urmatoarele cerinte:

1) Sa afiseze la consola santierele si valoarea medie a obiectivelor (media
   valorilor estimate prin autorizatiile de constructie).
   Punctaj: 2 puncte.
   Criteriu de acordare a punctajului: afisarea corecta la consola.

2) Sa afiseze la consola cantitatile totale pentru fiecare capitol, astfel:
   cod capitol,cantitate
   ...
   Punctaj: 2 puncte.
   Criteriu de acordare a punctajului: afisarea corecta la consola.

3) Sa salveze in fisierul devize.txt o situatie a cheltuielilor la nivel de
   capitole, cu sumarizare pe santiere, astfel:

   cod capitol
   cod santier,valoare
   cod santier,valoare
   ...
   cod capitol
   cod santier,valoare
   cod santier,valoare
   ...

   unde 'valoare' se calculeaza prin inmultirea cantitatii cu pretul unitar.
   Punctaj: 2 puncte.

(NOTA: cerinta 4 si observatiile nu erau vizibile in poza - era taiata.)
